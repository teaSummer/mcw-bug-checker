# mcw-bug-checker

A project to automatically check for results of bug templates in Minecraft Wiki.

## Default

* wiki: Minecraft Wiki
* bot: [User:TeaSummerBot](https://zh.minecraft.wiki/w/User:TeaSummerBot) (zh)
* owner: [User:TeaSummer](https://zh.minecraft.wiki/w/User:TeaSummer) (zh)
* lang: zh (Chinese)
* level: 0b0111 (full-automatic)
* max_retries: 3
* namespace: 0, 4, 9994, 9996, 9998, 10000, 10002, 10004, 10006
