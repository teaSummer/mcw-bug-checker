# mcw-bug-checker

A project to automatically check for resolutions of `{{bug}}` templates in Minecraft Wiki.

## Configurations

* site: Minecraft Wiki
* bot: [User:TeaSummerBot](https://zh.minecraft.wiki/w/User:TeaSummerBot) (zh)
* owner: [User:TeaSummer](https://zh.minecraft.wiki/w/User:TeaSummer) (zh)
* lang: Chinese (`zh`)
* level: Full-automatic (`0b0111`)
* max_tries: `3`
* namespace: Default except 10010 (`[0, 9994, 9996, 9998, 10000, 10002, 10004, 10006]`)
